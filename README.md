# 銀花戦記 — Ginka Senki

スマートフォン縦持ち (9:16) 向け、固定視点の浅い2.5D戦術SLGの試作です。

## P01
- 高さ0/1/2の地形。段差1までは移動可能
- 味方フェイズ → 敵フェイズの交代制
- 移動先を2回タップして確定
- 攻撃、HP、敵の危険範囲
- 固定カメラ（回転・切り替えなし）
- 単体HTML。外部依存なし
